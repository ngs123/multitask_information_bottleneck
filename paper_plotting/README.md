# Paper figures and tables

Open `paper_experiment_plots.ipynb` and run all cells. Its shared implementation
is `plot_helpers.py`. Install `../requirements.txt` for plotting and Jupyter.
The notebook resolves all default paths from an explicit `REPO_ROOT`, detected
from the working directory or its ancestors. Set `MIB_REPO_ROOT` to the absolute
repository path when starting elsewhere. CelebA diagnostic imports resolve from
the helper's file location.

Default inputs, relative to the repository root:

- `celeba_experiment/runs/robust_rate_selection`: retained local CelebA results.
- `paper_plotting/inputs/dsprites_all_runs.csv`: tracked input snapshot copied
  from `dsprites_experiment/runs/dsprites_1/summary/all_runs.csv`. It contains
  168 runs: 14 beta settings × 3 seeds × 4 objectives, including the 6.19-bit
  table row. It is a fixed plotting input, not regenerated by this notebook.

The default specialist is `joint_attributes`. Outputs go to
`paper_plotting/paper_figures/` at the repository root.

Gaussian measured-NLL and proxy-moment uncertainty remain distinct. Proxy mode
requires a complete moment bootstrap. Optional appendix input paths remain in
the notebook; missing controls are not inferred from the primary experiment.
See [the CelebA README](../celeba_experiment/README.md) for available outputs,
missing inputs, training/recovery commands, and manuscript discrepancies, and
[the root README](../README.md) for installation and validation commands.

notebook execution. The rank heatmap stays in the appendix to preserve legibility.
The current main Gaussian panel uses test-image resampling conditional on fitted
channels. It is **not** the specification's moment-refitting interval. Proxy mode
requires a complete moment bootstrap (currently only 199/200 fits are available).

floor. Captions state actual resampling counts instead of the spec's placeholders.
The Gaussian reference in dSprites is a surrogate, not an exact prediction for
discrete image factors or their variational rate bound.

## Role swap and null control

From `dsprites_experiment/`, run:

```bash
python launch.py --config configs/role_swap.json --data-dir data/dsprites \
  --gpus 0,1,2,3 --out runs/dsprites_role_swap
python launch.py --config configs/null_control.json --data-dir data/dsprites \
  --gpus 0,1,2,3 --out runs/dsprites_null_control
```

Each configuration runs **42 mixture jobs** (14 betas × 3 seeds), matching the
main model, split protocol, and training schedule. `--dry-run` lists the planned
configuration without training. The launcher generates `summary/selected_runs.csv`
after successful completion. The plotting notebook detects these default paths;
rerun it to produce `role_swap/role_swap.pdf` and `null_control/null_control.pdf`.
Do not concatenate controls with the main input snapshot.

The swap uses ordered factors `posY,posX`: task 1 remains common/moderate and
task 2 remains rare/precise. The control plot holds physical identity fixed:
**horizontal minus vertical**, with horizontal now task 2. Its expected crossing
is negative-to-positive. The role-based common-minus-precise gap would still
cross positive-to-negative; merely reversing the main CSV columns is not evidence
for this control. Factor provenance is checked before plotting.

The null uses `task_weights=[0.5,0.5]` and
`noise_variances=[0.0625,0.0625]` throughout the loss, probe, and evaluation.
The CSV must record these settings. Its gap bars show the across-seed range,
not a confidence band over three seeds. The summary records whether each range
contains zero; it never forces a null result or claims statistical equivalence.
No M-family Gaussian reversal marker is drawn for the null.

Validation from the repository root:

```bash
python -m unittest discover -s paper_plotting/tests -v
(cd dsprites_experiment && DSPRITES_TEST_CACHE=data/dsprites python -m unittest discover -s tests -v)
```


## Curated Experiment Details appendix

`paper_figures/appendix/` contains exactly the 17 publication assets referenced
by `../docs/appendix_methods.tex` (15 PDFs and two LaTeX tables). Rebuild with
`python paper_plotting/prepare_appendix.py` from the repository root. Numerical
provenance and asset hashes are written to `../docs/appendix_values.json`.

This bundle includes the completed role swap, covariance spectra derived from
saved training features, and fine-tuned measured-NLL curves recovered from saved
per-image losses. It does not require neural retraining. The fine-tuned backbone
used all 40 CelebA labels, so the text identifies it as task-informed. Null,
shrinkage, and constructed-worst-case/SNR-cap results remain unavailable.
The notebook's `missing_figure_inputs.txt` concerns its configured input slots;
the curated builder independently recovers the spectrum and fine-tuned figure.


The complete CelebA bank now appears as measured-NLL curves for Gaussian and
binary-code representations, including all eight pretexts and both reference
objectives. The decoder-capacity figure shows both mechanisms side by side.
Only proxy-versus-measured NLL receives a regression-fit score: OLS with an
intercept gives in-sample R² = 0.981512, slope 0.701817, intercept -0.004594.
Accounting and code-entropy plots retain identity lines without R² annotations.
